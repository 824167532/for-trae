# 开票待办助手

一款简单高效的本地发票管理工具，帮助财务人员快速管理开票待办事项。

## 功能特点

- 🎯 **截图粘贴归档**：直接从剪贴板粘贴截图，自动保存到指定目录
- 🏢 **客户管理**：支持手动添加和Excel批量导入客户
- 📋 **待办列表**：清晰展示待开票、已开票、未发送、已发送状态
- 📁 **快捷打开**：一键打开对应月份文件夹
- 🔔 **查重提醒**：同一客户同一月份重复添加时提示
- 📊 **遗漏检查**：快速发现当月无开票记录的客户
- 📜 **历史记录**：方便查询历史开票记录
- 🎨 **玻璃拟态设计**：现代美观的UI界面
- 🖥️ **跨平台支持**：同时支持 Windows 和 macOS

## 快速开始

### Windows 用户

1. 双击运行 `start.bat`
2. 等待自动安装依赖（首次运行时）
3. 浏览器会自动打开 http://127.0.0.1:5000
4. 如果没有自动打开，请手动在浏览器输入上述地址

### macOS 用户

1. 在终端中进入项目目录
2. 执行以下命令：
   ```bash
   chmod +x start.sh
   ./start.sh
   ```
3. 或直接执行：
   ```bash
   python3 app.py
   ```
4. 浏览器会自动打开 http://127.0.0.1:5000

### Linux 用户

1. 确保已安装 Python 3.8+
2. 在终端中进入项目目录
3. 执行以下命令：
   ```bash
   pip install flask openpyxl
   python3 app.py
   ```
4. 浏览器访问 http://127.0.0.1:5000

## 功能说明

### 1. 客户管理

1. 点击顶部导航「设置」进入设置页面
2. 可以手动添加客户或下载Excel模板批量导入
3. 每个客户需设置显示名称和相对路径（用于文件存储）

### 2. 截图归档

1. 在飞书/微信/截图工具中复制图片到剪贴板
2. 在主页面的「截图粘贴区」点击后按 `Ctrl+V` (Windows) 或 `Cmd+V` (macOS)
3. 在弹窗中选择客户、确认业务月份，可修改文件名称
4. 点击确认，截图自动保存到指定目录

### 3. 待办管理

1. 在主页面查看所有待办事项（默认显示未发送）
2. 通过筛选栏可以按发送状态、客户、业务月份筛选
3. 点击「刷新状态」扫描 invoices 文件夹，有发票文件的待办自动变为「已开票」
4. 点击「标记已发送」将待办状态改为已发送

### 4. 文件目录结构

```
{您设置的根目录}/
├── {客户相对路径}/
│   ├── {业务月份}/
│   │   ├── screenshots/          # 截图存放目录
│   │   │   ├── 客户名_月份_时间戳.png
│   │   │   └── ...
│   │   └── invoices/              # 发票存放目录
│   │       ├── xxx.pdf
│   │       ├── xxx.xml
│   │       └── ...
```

### 5. 当月遗漏检查

点击顶部的「检查遗漏」按钮，快速列出当月没有任何待办记录的客户。

### 6. 停止服务

在运行程序的命令行窗口中按 `Ctrl+C` 即可停止服务。

## 常见问题

### Q: 首次启动需要安装依赖，太慢怎么办？

A: 可以使用国内镜像源加速安装。修改 Python pip 配置：
```bash
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

### Q: 根目录在哪里设置？

A: 在设置页面中输入您想存放文件的根目录路径，例如：
- Windows: `D:\财务资料\开票`
- macOS: `/Users/您的用户名/Documents/财务资料`

### Q: 如何打开客户文件夹？

A: 在待办列表中点击「打开文件夹」按钮，系统会用文件管理器打开对应月份的目录。

### Q: 开票状态如何更新？

A: 将发票PDF文件放入客户月份目录的 invoices 子文件夹中，然后点击「刷新状态」按钮，系统会自动检测并更新状态。

### Q: 数据保存在哪里？

A: 所有待办和客户信息保存在 `data/invoice_helper.db` 文件中（SQLite数据库），请定期备份此文件。

## 注意事项

1. 请勿关闭正在运行的命令行窗口，否则服务会停止
2. 首次使用请先进入「设置」页面配置根目录并添加客户
3. 建议定期备份 `data/invoice_helper.db` 文件
4. 根目录路径建议使用纯英文路径，避免特殊字符
5. 同一客户同一月份建议只创建一个待办记录
